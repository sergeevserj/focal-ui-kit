Дизайн-система Sura и интерактивная документация Focal UI Kit. Актуальный экспорт: 29 октября 2026 года.

## Просмотр и скачивание

Откройте опубликованный UI Kit по ссылке выше. Для локального просмотра скачайте `FoCal_UI_Kit.html` и откройте его в браузере: сборка и сервер не нужны, шрифты и иконки встроены. Все файлы проекта можно скачать через **Code → Download ZIP**.

## Исходники

| Путь | Содержимое |
| --- | --- |
| `index.html` | Главная страница GitHub Pages |
| `FoCal_UI_Kit.html` | Полный автономный UI Kit с документацией и интерактивными примерами |
| `src/ui-kit.css` | Все стили и классы компонентов, включая встроенные шрифты |
| `src/scripts/` | Скрипты интерактивных примеров и скачивания иконок |
| `tokens/primitives.css` | Общие CSS-переменные из `:root` |
| `tokens/primitives.json` | Те же значения в JSON, ссылки `var(...)` сохранены |
| `icons/` | Исходные SVG каждого размера, sprite и манифест с SHA-256 |
| `downloads/` | Архив всех иконок |
| `extract_sources.py` | Повторяемое извлечение исходников из автономного HTML |

HTML содержит примеры разметки компонентов. CSS и JS извлечены из него без переписывания поведения. Скрипты демонстраций предполагают соответствующую HTML-разметку; для переноса в приложение берите необходимые классы и реализуйте продуктовую логику.

## Правила использования

- Используйте существующие токены цветов, расстояний, радиусов и текста; точные значения и состояния смотрите в UI Kit.
- Inter — шрифт компонентов. Все кнопки имеют радиус 8 px.
- Каждый размер иконки — самостоятельный SVG: **12 / 16 / 24 / 32 px**. Не масштабируйте один размер вместо другого.
- Два источника `arrow_left` сохранены отдельно: суффикс содержит ID Figma.
- `system_message` может иметь любую ширину; тень настраивается переключателем «Тень».
- `inline_message` встраивается в интерфейс и всегда используется без тени.
- Состояния и значения в интерактивных примерах демонстрационные.

## Обновление

Замените `FoCal_UI_Kit.html` актуальным автономным файлом и выполните:

```sh
python3 extract_sources.py
```

Скрипт обновит страницу просмотра, CSS, JS, токены и SVG. После коммита GitHub Pages опубликует новую версию из ветки `main`, папка `/ (root)`.
